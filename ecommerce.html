Free WordPress plugins

Barebones PopUp

A simple popup for WordPress, written in plain HTML and CSS

Write the popup's content and its CSS on one admin screen. The popup appears on the homepage, or wherever you place the [barebones_popup] shortcode. JavaScript cannot be entered, which keeps the popup safe and light.

EarlyCart Sold

Bestseller and New arrival labels for WooCommerce products

Products in a category you choose get a Bestseller badge; all other products get a New arrival label with the number of units sold, counted from WooCommerce orders. For the bestseller category, the number shown is multiplied by a factor set in the settings. Labels can be restyled with your own CSS or template files.

What your store can get

  • A new WooCommerce store – setup, a custom theme, product pages, categories and filters.
  • Product data – import and export with CSV files, bulk changes with scripts and automation.
  • Cart and checkout – a short, clear path from the cart to the order.
  • Migration – moving a shop to a new platform or host, with its products, orders and addresses.
  • Custom plugins and API integration – features WooCommerce does not have out of the box.
  • Speed and security – fast product pages, updates, backups and only the plugins the shop really needs.
  • UX/UI and manual testing – the whole purchase checked on phones and computers before customers see it.
  • SEO for shops – product titles and descriptions, structured data and clean category addresses.

Store demos

What every website includes

  • Responsive design – the layout fits phones, tablets and large screens.
  • Fast loading – optimised images (WebP, responsive sizes), self-hosted fonts and only the code a page needs, with Core Web Vitals in mind.
  • Accessibility – built to WCAG 2.1 AA: keyboard navigation, readable contrast and labels for screen readers.
  • Ready for search engines – page titles, meta descriptions, structured data (schema.org), an XML sitemap and Open Graph tags for sharing.
  • Privacy – analytics only with the visitor's consent, through a cookie banner that needs no third-party plugin.
  • Easy updates – a custom WordPress theme with a CMS, or a lightweight static site, whichever suits the project.
  • Clean code – valid HTML and CSS, checked with the W3C validator.

Kinds of websites and web apps

  • Business, portfolio and personal websites
  • Landing pages for a product or a service
  • Online menus and ordering for restaurants
  • Booking and reservation systems for tours, appointments and events
  • Admin dashboards with charts and reports
  • Forms: sign-in, registration, multi-step applications and inquiries
  • Event, festival and ticket sites

This site – dkd.rs

This website: fast, accessible and private by default

Task. A personal website that loads quickly on phones, works for everyone and shares nothing about its visitors without their consent.

Solution. Hand-written HTML, CSS and JavaScript without a CMS or framework. One stylesheet holds only the rules the pages use; fonts are reduced to the characters the site needs and served from the same server; images are WebP in several sizes. The cookie banner is a custom script: Google Analytics, Microsoft Clarity and Meta Pixel load only after consent, with Google Consent Mode v2. The contact form is handled on the site's own server, with spam protection and no third-party form service. Plugin downloads are counted in a small SQLite database, without cookies or IP addresses.

Result. In Lighthouse lab tests (October 2026) the main pages score 97–100 for performance and 100 for accessibility, best practices and SEO. The HTML and CSS pass the W3C validator without errors, and axe finds no WCAG 2.1 AA violations.

Demo – WooCommerce-style booking shop

Meridia Travel: tour booking with a live price

Task. Let visitors find a tour, choose a date and see the full price before they book.

Solution. A tour archive filtered by region and month and sorted like a WooCommerce shop. Each tour page shows departures with places left, steppers for adults and children, a room type and extras with a total that updates as you choose. The basket accepts a coupon, and the checkout takes a 20% deposit or the full amount. Nothing is charged; it is a demo.

Shows. WooCommerce product templates, filtering and sorting, booking logic and a basket kept in the browser.

Demo – web application

Stackwise: an admin dashboard with accessible charts

Task. Show a shop's sales, customers and regions on six screens, in a way that also works for screen readers and without JavaScript.

Solution. The charts are SVG drawn by a custom script from a data table on the page. That same table is what screen readers and visitors without JavaScript get. Light and dark mode are remembered between visits.

Shows. Dashboard design, data visualisation without a chart library and accessible tables.

Open Stackwise

Demo – restaurant website

Olmara: ordering from an online menu

Task. Let guests order at the table or for takeaway, without installing an app.

Solution. 28 dishes in 7 categories with search and filters (vegetarian, vegan, gluten-free, spicy) and allergens for every dish. Guests choose quantities, see the order and total as they go, and add a table number or a pick-up time. On phones the order slides up from the bottom of the screen. The opening hours show whether the restaurant is open now.

Shows. An online menu and ordering system, mobile-first interaction and a filter interface.

Open Olmara

Demo – forms and UI kit

Fieldnote Forms: eight form designs for WordPress

Task. Forms people can fill in without guessing: sign-in, registration, password reset, contact, a multi-step project inquiry and a checkout.

Solution. A visible label for every field, messages next to the field that needs fixing, card numbers formatted while typing and a multi-step form that shows where you are.

Shows. Form design, client-side validation and accessible UI for WordPress sites.

Solution. Each plugin does one thing: a popup written in plain HTML and CSS, bestseller and new arrival labels for WooCommerce, and two dashboard plugins with a line of text on every admin page. The code is on GitHub, free to use and change.
